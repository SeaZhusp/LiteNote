# 轻签 LiteNote v1.4.0 发布视频脚本

> 面向用户的更新发布视频。围绕三个核心新功能：**快捷键自定义**、**复制待办**、**WebDAV 云同步（坚果云）**。
> 建议时长：2:30 ~ 3:30。节奏：先总览，再逐功能演示，最后收尾引导下载。

**画面**：桌面常驻的轻签毛玻璃小部件，鼠标点一下新增一条待办，再按 `⌘+Shift+L` 隐藏/唤出，展示「随手记一笔」的顺滑感。

**口播**：
> 大家好，这里是轻签 LiteNote。我们刚发布了 1.4.0 版本，这次主要带来三个大家呼声很高的功能：自定义快捷键、复制待办，以及终于支持的云同步。视频最后会告诉你怎么升级，先来看正片。

**字幕/标注**：v1.4.0 · 3 大更新

## 1. 功能一：快捷键自定义（0:20 - 0:55）

**画面**：打开设置（小部件右上角设置图标）→ 切到「快捷键」标签页。

**口播**：
> 以前快捷键是固定的，现在可以自己改了。设置里新增了「快捷键」页，三条分别是：显示/隐藏窗口、专注/完整模式切换、窗口置顶。
> 改法很简单——点一下右边的按钮，然后直接按下你想用的组合键，比如我把显示窗口改成 `⌘+Shift+Space`，松手就生效，后台会自动注册。如果不想要了，点那个小叉就能清空。两个快捷键设成一样会提示冲突，避免打架。

**操作提示（B-roll 切点）**：
- 进入路径：设置 → 快捷键 Tab
- 默认：`⌘+Shift+L` / `⌘+Shift+F` / `⌘+Shift+P`（Windows 为 `Ctrl+Shift+...`）
- 交互：点击按钮 → 按下组合键 → 自动保存注册；× 清除；冲突红框提示

**画面字幕**：支持清空 / 自动防冲突

---

## 2. 功能二：复制待办（0:55 - 1:35）

**画面**：在一条待办上右键 → 弹出上下文菜单 → 找到「复制到...」→ 选日期（今天/明天/本周末，或自定义）→ 列表里多出一条带新截止时间、内容颜色完全一致的副本。

**口播**：
> 第二条很实用——复制待办。比如你有一条「每周例会纪要」，右键选「复制到...」，选个目标日期，它就生成一条全新的、内容一模一样、但截止时间不同的待办。原始那条不动。
> 循环待办也能复制，适合把重复事项快速铺到不同日子。不用再一条条手敲了。

**操作提示（B-roll 切点）**：
- 触发：待办右键菜单 → 「复制到...」
- 目标日期：今天 / 明天 / 本周末 / 自定义日期
- 效果：生成新条目（新 ID），原文保留；颜色、重要程度、文本全部继承
- 提示 toast：「已复制」

**画面字幕**：复制后生成独立新条目，原条目不受影响

## 3. 功能三：WebDAV 云同步 · 坚果云（1:35 - 2:40）

**画面**：设置 → 「同步」标签页。开关「启用 WebDAV 同步」打开；「同步方式」显示「坚果云」；填入服务器地址、账号、密码；点「测试连接」→ 成功；点「立即同步」→ 状态显示「同步成功」+ 上次同步时间更新。

**口播**：
> 最重磅的是云同步。1.4 接入了 WebDAV，目前官方内置了坚果云。你只要在设置里打开同步开关，填入坚果云的服务器地址、账号和密码——密码是本地加密存储的，不会明文落盘。
> 同步是**双向**的，每 5 分钟自动跑一次：你在电脑 A 改了，电脑 B 上也会合并过来，互不影响。也可以点「立即同步」手动触发，或者「测试连接」先验证一下账号对不对。
> 如果是新设备，用「从云端恢复」就能把云上的待办拉回本机。

**操作提示（B-roll 切点）**：
- 进入路径：设置 → 同步 Tab
- 服务器地址默认占位：`https://dav.jianguoyun.com/dav/`
- 关键按钮：`测试连接` / `立即同步` / `从云端恢复`（恢复会覆盖本机，有二次确认）
- 状态反馈：连接测试中… / 同步中… / 同步成功 / 上次同步时间

**画面字幕**：
- 双向同步 · 每 5 分钟自动
- 密码本地加密保存
- 「从云端恢复」会覆盖本机，操作前确认

> 录制备注：演示「从云端恢复」时务必用测试账号，避免误覆盖真实数据。
